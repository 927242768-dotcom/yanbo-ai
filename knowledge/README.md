# 彦博本地知识库

把需要彦博长期参考的资料放到本目录中，服务会在提问时自动检索相关片段，不需要重新训练 LoRA。

当前支持：

- `.txt`、`.md`
- `.json`、`.jsonl`、`.csv`
- `.py`、`.c`、`.h`、`.cpp`、`.hpp`
- `.js`、`.ts`、`.java`、`.sql`

建议：

1. 一个文件只放一个明确主题；
2. 标题、章节名和专业术语尽量保留；
3. 单个生成后的知识文件不要超过 20 MB；
4. 可把 PDF、Word、图片、文本或代码文件拖到 `13_import_knowledge.bat` 上自动导入；
5. 扫描版 PDF 如果没有可提取文字，需要先做 OCR 或拆成图片导入。

`README.md` 本身不会被加入知识索引。
